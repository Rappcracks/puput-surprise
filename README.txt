WEBSITE KEJUTAN ULANG TAHUN - PU PUT

CARA MEMBUKA
1. Ekstrak file ZIP.
2. Buka index.html dengan Chrome / Edge.
3. Klik ikon ⚙ di kiri atas untuk mengedit tulisan, foto, dan musik.

CARA EDIT
- Isi tulisan: ubah melalui panel ⚙ lalu klik Simpan perubahan.
- Foto: pilih foto utama. Untuk Memory, pilih banyak foto sekaligus pada input Foto kenangan (Ctrl + klik untuk memilih beberapa). Foto tampil satu per satu dengan tombol Sebelumnya/Berikutnya. Gambar otomatis diperkecil agar lebih hemat ruang browser.
- Musik: lagu Still With You – Jung Kook sudah ada di folder assets dan langsung tersedia di halaman Music. Tekan Play untuk memutar. Jika memilih MP3 lain dari panel edit, file pilihan berlaku selama halaman tersebut masih terbuka; untuk mengganti permanen, ganti file assets/still-with-you.mp3 dengan MP3 lain dan pertahankan nama file tersebut.
- Perubahan panel edit tersimpan di browser/perangkat yang digunakan.

MENGUBAH TANGGAL PILIHAN
Buka script.js dengan Notepad atau editor kode.
Ubah:
const dates = ["16-01-2001","10-11-2000","16-10-2026","08-08-2028"];
const correctDate = "10-11-2000";
Tanggal yang benar saat ini adalah 10-11-2000.

CATATAN
- Website ini merupakan rekreasi interaktif berdasarkan video referensi, bukan salinan kode asli.
- File musik dan foto tidak disertakan karena perlu memakai file milik sendiri.
- Untuk menjadikannya website online, unggah seluruh isi folder ini ke layanan hosting statis seperti GitHub Pages atau Netlify.
