WEBSITE KEJUTAN ULANG TAHUN — VERSI HANDPHONE

Paket ini sudah disiapkan agar nyaman dibuka di layar Android maupun iPhone.
Lagu Still With You sudah ikut disertakan.

CARA MEMBUKA DI ANDROID
1. Kirim file ZIP ini ke HP (misalnya lewat WhatsApp atau Google Drive).
2. Ekstrak file ZIP menggunakan File Manager.
3. Buka folder hasil ekstrak, lalu ketuk index.html.
4. Jika diminta memilih aplikasi, pilih Chrome atau browser lain.
5. Ketuk tombol Play pada halaman Music untuk memutar lagu.

CARA MEMBUKA DI IPHONE
1. Simpan ZIP ke aplikasi Files, lalu ketuk ZIP untuk mengekstraknya.
2. Buka folder hasil ekstrak dan ketuk index.html.
3. Jika Safari tidak dapat membuka file lokal dengan benar, unggah folder ini ke layanan hosting statis (misalnya Netlify Drop) agar mendapat tautan website.

AGAR PACAR BISA MEMBUKA DARI TAUTAN
ZIP ini adalah paket website, bukan tautan internet publik. Agar pacar cukup mengetuk satu link, unggah seluruh isi folder ini ke layanan hosting statis seperti Netlify Drop atau GitHub Pages, lalu kirim URL yang diberikan layanan tersebut. Jangan hanya mengirim index.html karena file lagu berada di folder assets.

CATATAN
- Jangan pisahkan index.html, script.js, dan folder assets.
- Lagu ada di assets/still-with-you.mp3.
- Untuk mengganti foto/teks, gunakan tombol roda gigi (⚙) di website.
- Musik mungkin tidak otomatis berjalan saat halaman dibuka; tekan Play karena browser HP membatasi autoplay.
