CARA UPLOAD KE GITHUB PAGES

1. Ekstrak ZIP ini di komputer.
2. Buka folder hasil ekstrak (di dalamnya langsung ada index.html, script.js, folder assets, Foto Utama, dan foto kenangan).
3. Upload SEMUA ISI folder tersebut ke root repository GitHub puput-surprise, bukan folder puput_fixed-nya.
4. Pastikan index.html dan script.js berada sejajar di root repository.
5. Commit perubahan, tunggu Pages selesai deploy, lalu buka website dan tekan Ctrl + F5.
